# ADR-013: Use the Apache License 2.0

- Date: 2026-11-13
- Status: Accepted

## Context

RepoDocs is intended to be open source and needs a permissive license suitable for commercial and community adoption.

## Alternatives

- MIT License.
- A copyleft license.
- Apache License 2.0.

## Decision

RepoDocs uses Apache License 2.0, including its explicit patent grant and related protections.

## Consequences

The repository should include the complete Apache 2.0 license text and appropriate notices before the first public release.
